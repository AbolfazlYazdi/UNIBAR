۱. فونت‌های فعلی سایت

۲. افزودن فونت جدید

فایل‌های woff2، woff، ttf یا otf را انتخاب کن. فایل woff2 کم‌حجم‌تر است و سایت را سریع‌تر نگه می‌دارد. اگر فونت «متغیر» (variable) است تیک مربوطه را بزن تا همه‌ی وزن‌ها کار کند.

۳. خروجی

  1. فایل‌های فونت جدید را با همان نام نشان‌داده‌شده داخل پوشه‌ی fonts مخزن GitHub بگذار (دکمه‌ی «دریافت فایل» همان نام درست را می‌دهد).
  2. فایل index.json دریافت‌شده را هم داخل پوشه‌ی fonts جایگزین کن.
  3. تغییرات را commit کن. بعد از چند لحظه، دکمه‌ی Aa بالای صفحه‌ی کاربران این فونت‌ها را نشان می‌دهد.
